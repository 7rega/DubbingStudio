# DubStudio MCP Server (`dubstudio`)

Универсальный сервер по протоколу **Model Context Protocol (MCP)** для управления запущенной студией дубляжа **DubStudio** напрямую из AI-агентов: **Claude Code, Antigravity, Cursor, Windsurf, OpenCode, Codex**.

---

## 🚀 Способы подключения

Убедитесь, что DubStudio запущена (сервер слушает `http://127.0.0.1:8765`).

### 1. Claude Code (Прямой HTTP транспорт)
```bash
claude mcp add --transport http dubstudio http://127.0.0.1:8765/mcp
```

### 2. Cursor / Windsurf
Добавьте в файл `.cursor/mcp.json` (или Настройки → Features → MCP):
```json
{
  "mcpServers": {
    "dubstudio": {
      "type": "streamable-http",
      "url": "http://127.0.0.1:8765/mcp"
    }
  }
}
```

### 3. Antigravity (Google DeepMind CLI)
Добавьте в файл `~/.gemini/config/mcp_config.json`:
```json
{
  "mcpServers": {
    "dubstudio": {
      "command": "python",
      "args": ["-u", "F:/DubbingStudio/tools/mcp/dubstudio_mcp_bridge.py"]
    }
  }
}
```

### 4. OpenCode / Codex
```json
{
  "mcpServers": {
    "dubstudio": {
      "url": "http://127.0.0.1:8765/mcp"
    }
  }
}
```

## 🛠 Доступные инструменты (Tools)

| Инструмент | Назначение |
|:---|:---|
| `dub_status` | Проверка статуса DubStudio, активного проекта, GPU и возможностей. |
| `dub_get_project` | Метаданные открытого проекта (длительность, языки, настройки аудио). |
| `dub_get_segments` | Получение списка реплик с расчётом **CPS** (скорости речи) и статусом укладки (`ok`, `too_fast`, `too_slow`). |
| `dub_get_segment_context` | Чтение конкретной реплики с контекстом предшествующих и последующих фраз. |
| `dub_update_segment` | Обновление перевода (`tgt_text`), оригинального текста, голоса или спикера. Автоматически помечает реплику как `dirty` для озвучки. |
| `dub_split_segment` | **Разрезание фразы**: делит сегмент на 2 части по секундам (`split_at`) с распределением текста. |
| `dub_merge_segments` | **Склейка фраз**: объединяет 2 или более последовательных сегментов в один с общим окном тайминга. |
| `dub_adjust_timing` | Микро-подгонка границ (`start`, `end`) или сдвиг всего сегмента (`shift_seconds`). |
| `dub_tune_tts` | Настройка параметров генерации: температура и сид Higgs, стилевой промпт, шаги диффузии и CFG для VoxCPM2. |
| `dub_synth_segments` | Запуск переозвучки только изменённых (`dirty`) реплик. |
| `dub_mix_audio` | Пересведение звуковых дорожек в итоговый мастер-трек `dub_audio.m4a`. |
| `dub_retranslate` | Пакетный ре-перевод через внутреннюю нейросеть (Gemma / OpenRouter) с передачей стиля. |

## 💡 Примеры промптов для агента

* *«Посмотри сегменты с 10 по 25. Есть ли фразы с превышением темпа речи (too_fast)?»*
* *«В сегменте 14 перевод слишком длинный. Сократи текст так, чтобы фраза укладывалась в 1.8 секунды, и обнови сегмент.»*
* *«Разрежь сегмент 8 на 14.5 секунде, первая часть: 'Привет', вторая часть: 'как твои дела?'.»*
* *«Склей сегменты 20 и 21 в одну реплику и объедини их текст.»*
* *«Для сегмента 12 поставь температуру Higgs 0.85, сид 42 и запусти ре-синтез.»*
