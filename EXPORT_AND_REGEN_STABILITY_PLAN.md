# План реализации: Стабильность экспорта, защита дублей и очистка референсов в Dub Studio

## 1. Цель и решаемые проблемы

Данный план устраняет 4 критических риска сбоев и потери пользовательских данных при регенерации и экспорте:
1. **Краш экспорта видео:** падение ffmpeg при недоступности аппаратного NVENC на видеокартах AMD/Intel, старых GPU или при занятости энкодера.
2. **Падение по VRAM при мультиязычном экспорте:** одновременный запуск рендера на несколько языков перегружает память видеокарты.
3. **Стирание утверждённых дублей:** кнопка «Перегенерировать всё» или смена голоса стирает удачные фразы, которые пользователь отбирал вручную.
4. **Гул и артефакты в `emo_ref`:** эмоциональный референс клонирует посторонний шум (взрывы, выстрелы, тарелки ударных) из грязных сцен оригинала.

## 3. Детальные задачи по 4 направлениям

### Задача 1. Автоматический каскадный CPU-фолбэк при сбое NVENC
* **Файл:** [crates/dub-captions/src/burn.rs](file:///d:/DubStudio/crates/dub-captions/src/burn.rs)
* **Реализация:**
  1. В функции `burn(...)` обернуть вызов `run_ffmpeg` с флагом `gpu_encode`:
     ```rust
     let res = if gpu_encode {
         run_ffmpeg(video, &vargs, &nv, out, gpu_decode, timeout)
     } else {
         run_ffmpeg(video, &vargs, &sw, out, false, timeout)
     };
     
     match res {
         Ok(()) => Ok(()),
         Err(e) if gpu_encode => {
             eprintln!("[burn] Аппаратный NVENC вернул ошибку ({e}) -> автоматический откат на процессорный libx264...");
             run_ffmpeg(video, &vargs, &sw, out, false, timeout)
         }
         Err(e) => Err(e),
     }
     ```
  2. Видео гарантированно экспортируется на любых компьютерах и видеокартах без прерывания джобы.

---

### Задача 2. Безопасный мультиязычный экспорт (Очередь + Общие стемы)
* **Файлы:** [crates/dub-server/src/render.rs](file:///d:/DubStudio/crates/dub-server/src/render.rs) и API-эндпоинты
* **Реализация:**
  1. **Строгая последовательная очередь (Sequential Queue):**
     * При запросе экспорта на $N$ языков (`[RU, ES, FR]`) задачи выполняются строго по очереди (1 язык за раз).
     * В VRAM никогда не запускаются две параллельные сессии модели или два тяжелых процесса кодирования видео.
  2. **Переиспользование стемов (`Shared Stems Cache`):**
     * Первый язык выполняет сепарацию и сохраняет `stems/instrumental.wav`.
     * Все последующие языки пропускают этап сепарации и мгновенно подхватывают готовый инструментал из кэша.

### Задача 3. Защита утверждённых дублей (Замок / Lock)
* **Файлы:** [crates/dub-server/src/patch.rs](file:///d:/DubStudio/crates/dub-server/src/patch.rs) и [frontend/src/App.tsx](file:///d:/DubStudio/frontend/src/App.tsx)
* **Реализация:**
  1. **В [patch.rs](file:///d:/DubStudio/crates/dub-server/src/patch.rs):**
     * Добавить операцию `op_lock_segment`: переключение флага `locked: bool` в `seg.extra`.
     * Обновить функцию `mark_all_dirty`:
       ```rust
       fn mark_all_dirty(p: &mut Project) {
           for seg in &mut p.segments {
               let is_locked = seg.extra.get("locked").and_then(|v| v.as_bool()).unwrap_or(false);
               if !is_locked {
                   seg.dirty = true;
               }
           }
       }
       ```
  2. **Во [frontend/src/App.tsx](file:///d:/DubStudio/frontend/src/App.tsx):**
     * Добавить кнопку с иконкой замка 🔒 на панели сегмента в редакторе и на таймлайне.
     * При активном замке фраза визуально помечается как «Закреплена», и общая перегенерация её не перезаписывает.

### Задача 4. Очистка `emo_ref` и авто-откат на чистый Identity-реф
* **Файлы:** [crates/dub-server/src/render.rs](file:///d:/DubStudio/crates/dub-server/src/render.rs) и [crates/dub-server/src/media.rs](file:///d:/DubStudio/crates/dub-server/src/media.rs)
* **Реализация:**
  1. **Полосовой фильтр Bandpass 80–8000 Hz:**
     * При нарезке `emoref_{sid}.wav` отсекать частоты ниже 80 Гц (сабвуферный гул взрывов, шагов, моторов) и выше 8000 Гц (шипение тарелок и синтезаторов).
  2. **Детектор чистоты (Energy & SNR Gate):**
     * Если средний уровень энергии реплики ниже $-32\text{ dBFS}$ (шепот, тонущий в шуме) или обнаружен высокий уровень фонового шума, `emo_ref_of` возвращает `None`.
     * Синтез автоматически переключается на проверенный чистый `identity-реф` спикера (`ref_of(s)`), защищая дубляж от посторонних шумов.

## 4. Верификация и тесты

1. **Тест NVENC Fallback:** Имитация сбоя NVENC (передача неподдерживаемого флага) $\to$ проверка автоматического завершения экспорта через `libx264`.
2. **Тест Lock Segment:** Блокировка фразы №2 замком 🔒 $\to$ вызов «Перегенерировать всё» $\to$ проверка, что аудиофайл фразы №2 не изменился.
3. **Тест чистоты `emo_ref`:** Прогон сцены со взрывом на фоне $\to$ проверка, что TTS взял чистый `identity-реф`, а не шумную сцену.
